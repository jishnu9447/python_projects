# Python Projects

This repository contains two Python projects developed using Python.

## 1. Tic Tac Toe Game

A simple two-player game developed using Python.

Features:
- 3x3 game board
- Two-player mode
- Win and draw detection
- Input validation
- Play again option

## 2. Student Management System

A database management application developed using Python and SQLite.

Features:
- User registration and login
- Admin and Staff roles
- Add student details
- View student records
- Update student details
- Delete student records
- SQLite database connectivity

## Requirements

- Python 3.x
- SQLite3

## How to Run

1. Download or clone this repository.
2. Open the project in PyCharm.
3. Run `tictaktoe.py` for the Tic Tac Toe game.
4. Run `student_managment.py` for the Student Management System.
